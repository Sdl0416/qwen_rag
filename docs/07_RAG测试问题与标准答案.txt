企业RAG测试问题（建议先用这20题）

1. QM-Cam X3 默认在无 DHCP 服务时使用什么临时 IP？
标准答案：192.168.1.64。

2. QM-Cam X3 最高分辨率是多少？
标准答案：2560×1440。

3. 摄像机夜间画面过曝应该怎么处理？
标准答案：降低红外强度或调整安装角度，避免近距离反射物。

4. NVR 最多支持多少路摄像机？
标准答案：8 路。

5. 单路 4Mbps 全天录像每天大约产生多少数据？
标准答案：约 43GB。

6. NVR 硬盘异常时首先应该检查什么？
标准答案：SATA 连接和供电，并执行 SMART 检测。

7. QM-Access A5 支持哪些认证方式？
标准答案：刷卡、PIN、人脸，可单独或组合使用。

8. 高安全区域推荐什么认证方式？
标准答案：双因素认证，例如人脸+卡。

9. 连续认证失败多少次会暂时锁定？
标准答案：5 次。

10. 门禁设备人脸识别率低应该如何处理？
标准答案：重新采集人脸，避免背光和遮挡，保持合适距离。

11. 企业知识库默认 Chunk Size 是多少？
标准答案：700 字符。

12. 默认 Chunk Overlap 是多少？
标准答案：120 字符。

13. 默认 Top-K 是多少？
标准答案：3。

14. Top-K 太大可能带来什么问题？
标准答案：引入无关上下文和噪声。

15. 扫描版 PDF 为什么可能搜索不到？
标准答案：无法直接提取文本，需要先做 OCR。

16. RAG 回答与文档不一致时，第一步应该看什么？
标准答案：先查看检索来源，判断是否召回了正确文档。

17. API 返回 404 时优先检查什么？
标准答案：接口地址和模型名称。

18. API Key 应该如何保存？
标准答案：使用环境变量或密钥管理服务，不应写入公开代码仓库。

19. 员工离职后账号什么时候应禁用？
标准答案：离职当日。

20. 知识库没有足够信息时系统应该怎么回答？
标准答案：明确提示“知识库中没有足够信息”，不要凭空补充。
